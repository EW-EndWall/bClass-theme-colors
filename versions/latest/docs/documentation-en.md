# bClass Theme Colors Documentation

## Overview

This project provides a collection of theme colors designed for web applications. Each theme is defined using CSS custom properties (variables) that can be applied to different parts of a webpage.

## Usage

To use a specific theme, add the corresponding class to your body element:

```html
<body class="blue-crane"></body>
```

Each theme defines the following CSS variables:

- `--headerBg` - Header background color
- `--footerBg` - Footer background color
- `--headerText` - Header text color
- `--footerText` - Footer text color
- `--contentBg` - Content background color
- `--contentBgPrimary` - Primary content background color
- `--contentBgSecondary` - Secondary content background color
- `--contentTextPrimary` - Primary content text color
- `--contentTextSecondary` - Secondary content text color
- `--plainBg` - Plain background color

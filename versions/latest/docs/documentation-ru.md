# bClass theme colors

## Обзор

Этот проект предоставляет коллекцию темных цветов для веб-приложений. Каждая тема определяется с помощью CSS-пользовательских свойств (переменных), которые могут быть применены к различным частям веб-страницы.

## Доступные темы

4. **blue-crane** - Цветовая схема синего цвета

## Использование

Чтобы использовать определённую тему, добавьте соответствующий класс к элементу body:

```html
<body class="blue-crane"></body>
```

Каждая тема определяет следующие CSS-переменные:

- `--headerBg` - Цвет фона заголовка
- `--footerBg` - Цвет фона нижнего колонтитула
- `--headerText` - Цвет текста заголовка
- `--footerText` - Цвет текста нижнего колонтитула
- `--contentBg` - Цвет фона содержимого
- `--contentBgPrimary` - Основной цвет фона содержимого
- `--contentBgSecondary` - Вторичный цвет фона содержимого
- `--contentTextPrimary` - Основной цвет текста содержимого
- `--contentTextSecondary` - Вторичный цвет текста содержимого
- `--plainBg` - Цвет обычного фона

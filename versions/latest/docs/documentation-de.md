# bClass theme colors

## Übersicht

Dieses Projekt bietet eine Sammlung von Theme-Farben für Webanwendungen. Jedes Theme wird mit CSS-Eigenheitsvariablen (Variablen) definiert, die auf verschiedene Teile einer Webseite angewendet werden können.

## Verwendung

Um ein bestimmtes Theme zu verwenden, fügen Sie die entsprechende Klasse zum body-Element hinzu:

```html
<body class="blue-crane"></body>
```

Jedes Theme definiert die folgenden CSS-Variablen:

- `--headerBg` - Header-Hintergrundfarbe
- `--footerBg` - Footer-Hintergrundfarbe
- `--headerText` - Header-Textfarbe
- `--footerText` - Footer-Textfarbe
- `--contentBg` - Inhalts-Hintergrundfarbe
- `--contentBgPrimary` - Primäre Inhalts-Hintergrundfarbe
- `--contentBgSecondary` - Sekundäre Inhalts-Hintergrundfarbe
- `--contentTextPrimary` - Primäre Inhalts-Textfarbe
- `--contentTextSecondary` - Sekundäre Inhalts-Textfarbe
- `--plainBg` - Einfacher Hintergrundfarbe

# bClass Tema Renkleri Dokümantasyonu

## Genel Bakış

Bu proje, web uygulamaları için tasarlanmış bir tema renk koleksiyonu sağlar. Her tema, CSS özel özellikleri (değişkenler) kullanılarak tanımlanır ve bu özellikler web sayfasının farklı bölümlerine uygulanabilir.

## Kullanım

Belirli bir temayı kullanmak için body elementine ilgili sınıfı ekleyin:

```html
<body class="blue-crane"></body>
```

Her tema aşağıdaki CSS değişkenlerini tanımlar:

- `--headerBg` - Başlık arka plan rengi
- `--footerBg` - Altbilgi arka plan rengi
- `--headerText` - Başlık metin rengi
- `--footerText` - Altbilgi metin rengi
- `--contentBg` - İçerik arka plan rengi
- `--contentBgPrimary` - Birinci içerik arka plan rengi
- `--contentBgSecondary` - İkinci içerik arka plan rengi
- `--contentTextPrimary` - Birinci içerik metin rengi
- `--contentTextSecondary` - İkinci içerik metin rengi
- `--plainBg` - Düz arka plan rengi

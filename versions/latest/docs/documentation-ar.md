## الاستخدام

لاستخدام موضوع معين، أضف الكلاس المقابل إلى عنصر body:

```html
<body class="blue-crane"></body>
```

يعرّف كل موضوع المتغيرات CSS التالية:

- `--headerBg` - لون خلفية الرأس
- `--footerBg` - لون خلفية التذييل
- `--headerText` - لون نص الرأس
- `--footerText` - لون نص التذييل
- `--contentBg` - لون خلفية المحتوى
- `--contentBgPrimary` - لون خلفية المحتوى الأساسي
- `--contentBgSecondary` - لون خلفية المحتوى الثانوي
- `--contentTextPrimary` - لون نص المحتوى الأساسي
- `--contentTextSecondary` - لون نص المحتوى الثانوي
- `--plainBg` - لون خلفية عادية
